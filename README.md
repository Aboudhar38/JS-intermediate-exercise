# Intermediate Programming Exercises (JavaScript)

This archive contains individual JavaScript solution files for all five exercises:

1. `1_factorial.js` — Recursive factorial function with input validation.
2. `2_isPrime.js` — Prime number check optimized up to `Math.sqrt(n)`.
3. `3_sumArray.js` — Array summation using a `for` loop (without `reduce()`).
4. `4_countCharacter.js` — Character counter with optional case sensitivity.
5. `5_fibonacci.js` — Fibonacci sequence generator handling `count` values of `0` and `1`.

## Running the Files
You can run any file using Node.js:
```bash
node 1_factorial.js
```
